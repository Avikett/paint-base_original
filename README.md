Що робити, якщо «все пропало»?

Ситуація 1: Я написав код, заплутався і хочу все видалити, щоб почати з "чистого аркуша" (поточного стану гілки main)

    Дія: Не видаляй проєкт! Відкрий термінал і введи:
   
    git reset --hard origin/main
   
    Результат: Твій код миттєво стане таким же, як у main.

Ситуація 2: Я вже відправив (Push) зламаний код на GitHub, що можна швидко зробити?
 
    Дія: Виправ код у себе, зроби Commit, а потім у терміналі напиши:
 
    git push -f origin назва_твоєї_гілки
  
    Результат: Нова версія просто «перекриє» стару. Ніхто й не помітить помилки!

Ситуація 3: Я хочу спробувати щось небезпечне, щоб не зламати основний проєкт.

    Дія: Створи свою гілку! 
    
    git checkout -b my-experiments

    Результат: Малюй хоч квадратною лінією — основний main буде в безпеці.

Головне правило розробника:
 
    Не бійся ламати. GitHub пам'ятає все. Твоя помилка сьогодні — це просто рядок у протоколі, який ми викреслимо завтра.
